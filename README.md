# usmap
Тут вы можете скачать новый (30.05.26) usmap для ready or not.
Он вам может пригодиться если вы хотите вытащить текстуры или модели из модов для игры, или самих моделей игры, с помощью fmodel и umodel.

#P.s. данный usmap работает только для ready or not, под каждую игру нужен свой, вы можете найти его под свою игру у https://github.com/TheNaeem/Unreal-Mappings-Archive или сделать самому с помощью https://github.com/UE4SS-RE/RE-UE4SS/releases/download/experimental-latest/UE4SS_v3.0.1-953-gb872ad11.zip
